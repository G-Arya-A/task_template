# Kısaltmalar ve Terimler Sözlüğü (Glossary)

|----------|----------|-----------------|

## Terminoloji

| Terim | Açıklama |
|-------|----------|
| **Backlog** | Yapılması gereken görevler havuzu |
| **Sprint** | Belirli bir sürede yapılacak çalışmalar |
| **Kanban** | Görev yönetim sistemi |
| **Standup** | Günlük kısa toplantı |
| **Retrospective** | Sprint sonu değerlendirme toplantısı |
| **Definition of Done (DoD)** | Bir görevin tamamlandı sayılması için gereken koşullar |
| **Definition of Ready (DoR)** | Bir görevin başlamaya hazır olması için gereken koşullar |
| **Technical Debt** | Teknik borc - ngắn vadede yapılan ama uzun vadede sorun olan kararlar |
| **Code Smell** | Kodda potansiyel sorun gösteren belirtiler |
| **Refactoring** | Kod yapısını değiştirmeden iyileştirme |
| **Merge Conflict** | İki dal arasındaki çakışma |
| **Cherry-pick** | Belirli bir commit'i diğer dala aktarma |
| **Rebase** | Commit'leri yeniden yeniden taşıma |
| **Squash** | Birden fazla commit'i tek commit'e birleştirme |
